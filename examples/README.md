# Examples

Each file is a worked output written by following the skills for one invented event. The request at the top of each file is what the agent was given. Events, people, vendors, and prices are invented; prices are for showing the math only and are not typical costs. These examples were written by hand from the skill instructions, not captured from a live run in an AI tool.

| Example | Skills used |
| --- | --- |
| [Backyard wedding: planning](backyard-wedding-planning.md) | `event-brief`, `event-planning-timeline`, `event-budget-sheet` |
| [One-day conference: the day](one-day-conference-day-of.md) | `event-run-of-show`, `event-mc-script`, `event-contingency-plan` |
| [Company party: guests](company-party-guest-comms.md) | `event-guest-email`, `event-seating-plan` |

Use them to see what good output looks like, and as test cases when you change a skill: follow the changed skill with the same request and compare.
